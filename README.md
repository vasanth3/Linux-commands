# 🐧 Linux Commands for System Administration

Welcome to my Linux Commands Repository!

This repository is a practical collection of essential Linux commands, command-line examples, and shell scripting exercises. It is created to improve my Linux skills and build a useful reference for Linux System Administration.

The repository covers basic Linux commands, file management, user administration, permissions, networking, process management, storage, system monitoring, and shell scripting.

## 🎯 Objectives

- Learn and practice essential Linux commands.
- Understand Linux system administration concepts.
- Improve command-line troubleshooting skills.
- Practice shell scripting and automation.
- Build a practical Linux reference for daily use.

## 💻 Practical Examples

### Check System Information

```bash
hostname
uptime
uname -a
```

### Monitor Memory and Disk Usage

```bash
free -h
df -h
du -sh /var/log
```

### Manage Processes

```bash
ps aux
top
```

### Search Files and Text

```bash
find /var/log -type f
grep -i "error" /var/log/syslog
```
